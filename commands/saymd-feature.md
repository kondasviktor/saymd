# /saymd-feature

1. Run:

```bash
npx saymd@0.1.2 -o .ai/prompt.md --template feature
```

Or: `npx saymd@0.1.2 --file idea.m4a -o .ai/prompt.md --template feature`

2. Open / `@` `.ai/prompt.md`.
3. Confirm the feature Objective, then ask whether to implement.

First-run: `npx saymd@0.1.2 setup` → `npx saymd@0.1.2 doctor` if needed.
