# /saymd-feature

1. Run:

```bash
npx saymd -o .ai/prompt.md --template feature
```

Or: `npx saymd --file idea.m4a -o .ai/prompt.md --template feature`

2. Open / `@` `.ai/prompt.md`.
3. Confirm the feature Objective, then ask whether to implement.

First-run: `npx saymd setup` → `npx saymd doctor` if needed.
