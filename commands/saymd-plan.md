# /saymd-plan

1. Run:

```bash
npx saymd -o .ai/prompt.md --template plan
```

Or: `npx saymd --file plan.m4a -o .ai/prompt.md --template plan`

2. Open / `@` `.ai/prompt.md`.
3. Outline the numbered Steps, then ask whether to start step 1.

First-run: `npx saymd setup` → `npx saymd doctor` if needed.
