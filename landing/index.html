Frequently asked questions.

Everything you need to know before installing or upgrading.

What is saymd?

saymd is a terminal CLI that turns microphone recordings or audio files into structured Markdown prompts for AI coding agents. The goal is not just transcription — it is creating a reusable prompt artifact.

Why not just use built-in voice in Cursor, Claude Code, or Copilot?

Built-in voice is convenient, but the transcript usually stays inside that tool. saymd writes a reusable Markdown file you can keep in your project and use with different agents.

What does BYOK mean?

BYOK means Bring Your Own Key. You configure your own API keys for Google Gemini, OpenAI, Deepgram, or ElevenLabs — saymd does not sell transcription credits or host speech-to-text. Keys are stored locally in ~/.saymd/config.json. Audio goes to the provider you chose, not to saymd.app.

Which STT providers are supported?

Free includes all four: Gemini (gemini-3.5-transcribe, recommended), OpenAI (gpt-4o-transcribe), Deepgram (nova-3 multilingual), and ElevenLabs (scribe_v2). Run saymd setup to pick one and paste your key.

Which languages are supported?

saymd supports more than 85 input languages with automatic detection. Free output stays in the detected language. Pro adds cross-language output, such as speaking Hungarian and generating an English specification.

Which AI agents does it work with?

Any agent or coding tool that can read a Markdown file can use a saymd prompt. Common examples include Cursor, Codex, Claude Code, GitHub Copilot, Gemini CLI, and OpenCode.

Does saymd store my audio?

The CLI does not send audio to saymd.app. Audio is sent to the STT provider you chose (Gemini, OpenAI, Deepgram, or ElevenLabs) with your own API key. Local temporary files are kept only until the Markdown write succeeds, then deleted. See the Privacy Policy.

What is included in Free versus Pro?

Free includes voice/audio-file input, 85+ languages, structured Markdown, feature/bug/plan templates, and all four BYOK STT providers. Pro adds --continue, --review, cross-language output, and project vocabulary. There is no free Pro trial — upgrade when those features become part of your workflow.

Can I cancel anytime?

Yes. Use Manage subscription to open Stripe — invoices, card updates, and cancellation live there. Annual purchases also include a 14-day refund; email support@saymd.app if you need help.
