# saymd

**Not a hosted demo.** This Space is a pointer to the Free MIT CLI.

Agents execute. saymd delivers a usable spec — speak (or pass `--file`), get a structured Markdown prompt, then `@` it in Cursor, Claude Code, Codex, Copilot, Antigravity CLI, OpenCode, or any agent that reads Markdown.

## Start here

1. Open **[saymd.app](https://saymd.app/?utm_source=huggingface&utm_medium=space&utm_campaign=saymd)**
2. Or install locally: `npx saymd setup`
3. Secondary: [GitHub](https://github.com/kondasviktor/saymd)

**BYOK** — Bring Your Own Key (Gemini, OpenAI, Deepgram, or ElevenLabs). Audio goes to the provider you chose, not to saymd.app.

Pro (`--continue`, `--review`, `--out`, vocab) is a separate commercial package on saymd.app.
