# saymd

**Not a hosted demo.** This Space is a pointer to the Free MIT CLI.

**Voice inbox for your repo — voice notes become repo-grounded specs and task queues for any coding agent.** Talk it through on a walk; find the spec in your repo, ready for Claude Code, Codex, Cursor, Copilot, Antigravity CLI, OpenCode, or any agent that reads Markdown.

## Start here

1. Open **[saymd.app](https://saymd.app/?utm_source=huggingface&utm_medium=space&utm_campaign=saymd)**
2. Or install locally: `npx saymd@1.0.0 setup`
3. Secondary: [GitHub](https://github.com/kondasviktor/saymd)

**BYOK** — Bring Your Own Key (Groq, Gemini, OpenAI, Deepgram, or ElevenLabs). Audio goes to the provider you chose, not to saymd.app.

**Pro Local** (€49 one-time): `--split` turns one long memo into ordered task files, `--ground` makes specs reference your real files, and `saymd mcp` lets your agent pull the next task and mark it done. **Pro Cloud** (€9/month or €79/year, 14-day trial) adds a Telegram voice inbox with no API key.
