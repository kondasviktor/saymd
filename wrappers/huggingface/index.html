Voice inbox for your repo.

Talk it through on a walk; find the spec in your repo. Voice notes become repo-grounded specs and ordered task files for Claude Code, Codex, Cursor, Copilot, Antigravity CLI, OpenCode, and more.

Install → Speak → @prompt.md

  1. Install — npx saymd@1.0.0 setup
  2. Speak — mic or --file; get .ai/prompt.md
  3. @ the prompt — open it in your agent
npx saymd@1.0.0 setup
npx saymd@1.0.0 doctor
npx saymd@1.0.0 -o .ai/prompt.md --template feature --seconds 30

What you get

Structured Markdown

Objective, Context, Instructions, Constraints — not a raw transcript dump.

Task queues (Pro)

--split --ground: one long memo becomes .ai/tasks/01-db.md, 02-api.md … with real file paths; saymd mcp lets your agent pull the next one.

From your phone (Pro Cloud)

Send a voice note to the saymd Telegram bot; saymd inbox sync drops it into your repo. No API key.
