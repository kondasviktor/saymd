Agents execute. saymd delivers a usable spec — structured Markdown from messy speech, ready for Cursor, Claude Code, Codex, Copilot, Antigravity CLI, OpenCode, and more.

Install → Speak → @prompt.md

  1. Install — npx saymd setup
  2. Speak — mic or --file; get .ai/prompt.md
  3. @ the prompt — open it in your agent
npx saymd setup
npx saymd doctor
npx saymd -o .ai/prompt.md --template feature --seconds 30
